# FINVERSE app icon

The launcher icon source was generated with OpenAI's built-in image-generation
tool in `logo-brand` mode, then resized into Android density-specific PNGs.

Final generation prompt:

> Use case: logo-brand. Asset type: Android/iOS finance app launcher icon,
> square 1024x1024. Create a premium, simple FINVERSE app icon using an
> abstract upward financial path that also subtly forms the letter F, paired
> with a small circular coin/sun element. Style/medium: crisp vector-like
> geometric mark rendered as a polished raster icon; minimal, modern,
> trustworthy, distinctive at 48px. Composition/framing: centered symbol,
> generous safe padding (main mark within central 66%), rounded-square
> full-bleed background. Color palette: deep navy-to-indigo background,
> electric blue and restrained mint accent, high contrast. Constraints: no
> words, no letters drawn literally, no numbers, no dollar/currency symbols,
> no bank building, no gradients that become muddy at small sizes, no
> transparent background, no watermark, no mockup device, exactly one icon.

`finverse-app-icon.png` is the 1024x1024 source-of-truth asset.
